## Introduction
 This Project is a Dynamic Quiz App that fetches questions from the open Trivia Database API.

 ---

 ## Features
  - Multiple Questions categories.
  - customizable difficulty levels.
  - Test yout Knowledge
  - Real-time Score Tracking.
  -Mobile-friendly design
